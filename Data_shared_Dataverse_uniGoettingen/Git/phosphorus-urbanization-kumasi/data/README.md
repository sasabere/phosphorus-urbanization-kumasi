## Quick Download

### Automatic (Recommended)

```r

```

### Manual

1. Visit: https://doi.org/10.25625/DA3TOR
2. Download: **ksitotal_P.csv**
3. Place in this `data/` folder

---

## Dataset Description

**File:** `ksitotal_P.csv`  
**Samples:** 225 topsoil samples (0–10 cm)  
**Variables:** 81 columns

### Key Variables

- **Identifiers:** sample_id, field_ID
- **Urbanization:** class (weak/mild/moderate/strong)
- **Total P:** HNO₃ and multi-acid digestion
- **P Fractions:** PPa, PSOM, PCa, POCC (stocks & concentrations)
- **Soil Properties:** pH, SOC, exchangeable Ca, bulk density
- **Quality Flags:** LOQ status for each fraction

For detailed variable descriptions, see the Dataverse README.
